## Интерактивный редактор автомата Мура

- Каждому состоянию сопоставляется выходной символ (B), переходам — входной символ (A).
- Автоматическое создание состояний при добавлении переходов (если вершины ещё не существуют).
- Проверка корректности перехода (все поля заполнены, нет дублирующих пар q(t), A), с выводом понятных сообщений об ошибках.

## Панель редактирования переходов (Edge panel)

- Удобная форма ввода четверки q(t), A, B, q(t+1) для добавления переходов.
- Список всех переходов в текстовом виде (i. q --(A / B)--> q') с возможностью выбора.
- Удаление выбранного перехода одним кликом.
- Удаление состояния по имени с автоматическим удалением всех входящих/исходящих переходов.
- Полная очистка автомата (все состояния, выходы и переходы) с подтверждением.
- Счётчики количества переходов и состояний, автоматически обновляющиеся при изменениях.

## Панель анализа автомата (Analysis panel)

- Выбор начального состояния q0 из доступных состояний через выпадающий список.
- Отображение текущего начального состояния или его отсутствия.
- Автоматический вывод входного алфавита A и выходного алфавита B в виде множеств { a, b, ... }.
- Полная обработка слова:
  - Ввод слова над алфавитом A.
  - Проверка, что слово состоит только из допустимых символов, что задано начальное состояние и что автомат полон (для каждой пары q, a есть переход).
  - Пошаговый отчёт по обработке слова: последовательность состояний, входных и выходных символов, итоговое выходное слово и финальное состояние.
  - Текстовый результат в отдельной области (удобно копировать и анализировать).
- Очистка области результата одной кнопкой.

## Live‑Edit: пошаговая симуляция слова
- Запуск интерактивного режима по введённому слову (Start).
- По‑шаговая обработка слова (Next step): по одному символу с обновлением текущего состояния автомата.
- Автоматическая блокировка поля ввода слова на время симуляции, чтобы не нарушать сценарий.
- Индикатор текущей позиции в слове:
  - Слово отображается с подсветкой обрабатываемого символа (a b [c] d).
  - Отображение позиции вида pos i/n, с пометкой завершения (- done) при достижении конца.
- Отображение накопленного выходного слова по мере продвижения по шагам.
- Сброс Live‑Edit (Reset) с очисткой результата и разблокировкой ввода.
  
## Графическая визуализация автомата
- Центральная панель визуализации на базе tk.Canvas.
- Автоматическое размещение вершин по окружности с адаптацией к размеру окна.
- Отрисовка направленных рёбер с подписями вида A, B (входной и выходной символы).
- Корректная визуализация петель (переходов вида q → q) с дугами над вершиной.
- Выделение начального состояния на графе.
Поддержка динамического изменения размеров окна: перерисовка графа при ресайзе.

## Подсветка активного состояния и перехода

- Во время Live‑Edit автоматически подсвечивается текущее состояние.
- Подсвечивается активное ребро (q, A, q'), соответствующее последнему шагу обработки.
- Удобная визуальная связка между текстовой симуляцией и графом автомата.
  
## История изменений и Undo/Redo
- Автоматическое сохранение снимков состояния автомата при изменениях (добавление/удаление переходов,
- удаление состояний, смена начального состояния, очистка).
- До 50 шагов истории с возможностью отката назад (Undo) и вперёд (Redo).
- Актуальное состояние возможности Undo/Redo отражается в кнопках (активные/неактивные).
- Восстановление снимка полностью переписывает множества состояний, переходов и выходов, а также начальное состояние.
  
## Начальная демонстрационная конфигурация
- При запуске, если автомат пуст, автоматически создаётся небольшой демонстрационный граф (несколько состояний и переходов).
- Назначается разумное начальное состояние (q0 = 1), чтобы пользователь сразу видел работающий пример.
- Демонстрационный автомат можно редактировать, дополнять или полностью удалить.

## Согласованность панелей и архитектура
- Приложение реализовано по принципам разделения слоёв:
  - domain — модель автомата Мура.
  - services — бизнес‑логика и управление состоянием.
  - ui — интерфейс на Tkinter с панелями.
- Используется паттерн «Наблюдатель»: все панели подписаны на изменения состояния через StateManager.
- Любое изменение автомата в одной панели (добавление перехода, смена q0, Undo/Redo, Live‑Edit) немедленно отражается:
  - в списке переходов,
  - в алфавитах и начальном состоянии,
  - в визуализации графа и подсветке.
